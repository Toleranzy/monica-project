## 📋 О проекте

MONICA — это система для автоматизации работы сети салонов красоты. Она помогает:

- 🤖 Формировать оптимальные графики выездов на основе логистики
- 💬 Взаимодействовать с сотрудниками через Telegram-бота
- 🗣️ Управлять системой голосовыми командами
- 📊 Отслеживать историю салонов и продажи
- 🎯 Соблюдать индивидуальные интервалы обновления для каждого салона
